
# QuickCare - Service Booking App

This is a simple service booking website made using HTML, CSS and JavaScript.

## Features
- Navigation bar
- Browse different services
- Add services to cart
- Skip services
- Calculate total amount
- Booking form
- Responsive design

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or open the project folder.
2. Open index.html in your browser.
3. Select services and try the booking option.
